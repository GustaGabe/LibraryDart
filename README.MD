
# 📚 Library - Dart Language Study

This project is a simple study of the Dart programming language. It simulates a small digital library called **DartLibrary**, where books can be added to a list, and some basic information is printed to the console.

## 🧠 What You Will Learn

- How to create and manipulate a `List<Map>` in Dart  
- How to declare and use variables of different types: `String`, `double`, `bool`, `int`  
- How to define and call functions (including arrow functions)  
- How to print formatted output in the console  
- How to iterate over a list using `forEach`  

## 🛠️ How It Works

- A list named `livro` (Portuguese for "book") stores books as maps with title, author, and year.
- A function `adicionarLivro` is used to add new books to the list.
- The program prints:
  - The library name
  - The total number of books
  - A simple "tax calculation" using an arrow function
  - The availability of books
  - All book details

## 💡 Example Output

## 📌 Notes

- This is a beginner-level example meant for educational purposes.
